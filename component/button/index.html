Button

Clickable controls for primary actions—submit, open dialogs, or run commands. Customize style, size, and icons; group related actions with x-button-group.

#
Usage

Basic example with common props.

#
Variants

Color and style variants.

#
Icons

Leading, trailing, and icon-only buttons.

#
Tooltip

Buttons with hover tooltips.

#
Size

Size options from xs to lg.

#
Button Group

Joined buttons sharing a common group layout.

#
States

Disabled, loading, and other interactive states.
