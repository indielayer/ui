Datepicker

Date and time picker styled as a wrapper around @vuepic/vue-datepicker. Use it for forms that need calendar or datetime selection with Indielayer look and feel.
This component is just a wrapper for the @vuepic/vue-datepicker package to fit the look and feel. For more documentation please see @vuepic/vue-datepicker documentation.
